# 電気回路ラボ

中学2年 技術「エネルギー変換の技術／電気回路の仕組み」を、さわって確かめる学習ページです。

- ① 扇風機のモデル：スイッチ・可変抵抗器を操作し、実物の絵と回路図で電流の流れを見る
- ② 図記号クイズ：電気用図記号（JIS C 0617）を10問で確かめる
- ③ 回路図パズル：お題の回路図を記号で完成させる
- ④ LEDの抵抗：オームの法則で電流制限抵抗を求める
- ⑤ 回路シミュレーター（sim.html）：電池・スイッチ・抵抗・LED・豆電球・モータ・ブザー・光センサ（CdS）・トランジスタを置いて導線でつなぎ、動きを確かめる。部品の絵⇔回路図の切りかえ、ライトを当てると動く回路のお手本つき（簡略モデル）

登録不要・端末内だけで動きます。
